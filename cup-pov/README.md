# 杯底視角（Inside the cup POV）

把一張自拍做成「從抹茶杯底往上看」的效果：臉出現在杯口圓窗裡，周圍是綠色液體，冰塊慢慢旋轉，氣泡往上冒，吸管從嘴邊一路伸向鏡頭。

成片：`out/cup_pov.mp4`（1080×1350，24fps，10 秒，含氣泡與冰塊碰撞音效）

除了自拍之外，畫面全部用程式生成：
- 冰塊：用對數極座標排成透視隧道，再以圓角 Voronoi 分格做出冰塊，加上流動擾動、旋轉和下沉
- 液體：細小氣泡、水波光紋、離鏡頭越遠越亮的光線，近鏡頭的部分做景深模糊
- 杯口：魚眼放大臉部、模擬手持晃動、杯緣水面波動和玻璃反光
- 吸管：延伸到鏡頭前的半透明管子

## 重新渲染

```bash
pip install pillow numpy   # 另需 ffmpeg
python3 render.py --preview   # 先輸出幾張關鍵影格
python3 render.py
```

換照片：替換 `assets/selfie.jpg`，再調整 `render.py` 開頭的 `SRC_C`（臉部中心）和 `SRC_R`（取景半徑）。顏色、冰塊數量和旋轉速度也都在開頭的常數裡。
